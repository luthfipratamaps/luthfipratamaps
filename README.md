## 👨‍💻 About Me

I'm an **IoT engineer focused on end-to-end embedded and industrial systems**.

My work spans the complete engineering stack:

```text
Sensor
   ↓
Electronics / PCB
   ↓
Embedded Firmware
   ↓
Industrial Communication
   ↓
Network / Telemetry
   ↓

Monitoring & Deployment
```

I enjoy building systems where **hardware, firmware, networking, and software need to work together reliably in the real world**.
